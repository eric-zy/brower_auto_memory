# 页面适配要点

来源：用户提供的 WebBridge skill，标注实测日期 2026-10-21。以下内容尚未在本项目真实账号上验证。

- 新建向导 step0 包含剧信息、版权、备案、售卖与单集卡；step1 为批量传视频。集数由卡片数量决定，空卡片也可能静默阻塞下一步。
- 滚动容器可能是 `.home__main`；不要只滚动 window。下拉旧面板会残留，选择选项时检查当前可见性。
- “转授权权利”需要明确选择，普通点 label 可能无效。当前实现优先关联 input，再回读选中值；无法关联时停止校准。
- 版权证明为“类型+实际附件”；与授权推广文件是不同上传位。封面上传后可能出现裁剪弹窗。
- 版权有效期、备案号曾发生填后被清空；下一步前必须全量回读。日期控件、自定义下拉或多选无法可靠回读时停止，不凭日志认定填写成功。
- Vue 上传控件可能要求先触发上传框再注入文件。原 WebBridge 的结论不能直接证明 Browser Use 的 CDP 注入也需要相同步骤；当前先做白名单注入，不响应时停止并校准，不盲目点击系统文件框。
- 上传位置需对应单集序号，每次只传当前集的视频。同剧按集数串行处理，已有卡片数量需与页面实际集数一致，不能删旧卡或留空卡。
- 校验提示可能是浮层、居中弹窗，也可能完全无提示。点击无反应时先检查缺失字段、空卡及当前请求结果。
- 审核中后端可能返回 `result=116` 且前端静默；当前适配器没有业务响应监听，遇到静默阻塞停止并保存现场，需人工核对，不反复重试。
- 上传完成不是发布成功；最终需在目标作品详情的目标集数行读到实际审核状态。平台未显示集数 ID 时保留空值，不编造。

原验证清单中的既有剧加集流程与每次新建策略冲突。本版复用已确认的同剧作品 ID，不自动新建重名剧，不给审核中或已完结的剧加集。通过 `inspect_platform` 读取当前页面，而非执行旧命令入口。
